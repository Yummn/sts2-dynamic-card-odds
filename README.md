# 动态出率（Dynamic Card Odds）

这是一个给故障机器人卡牌奖励做自适应调整的 MOD。它会根据你实际看过和选过的牌，慢慢改变同稀有度卡牌之间的相对权重；目标不是替你固定流派，而是让奖励更贴近当前牌组和过往选择，同时给冷门牌保留重新出现的机会。

该功能最早包含在 BetterDefect 中，从 v0.11.35 起拆成独立项目，不依赖 BetterDefect 或 BaseLib。

## 它如何学习

- 只统计正好三张、且全部属于故障机器人的普通奖励；无色、混色和特殊奖励不会进入样本。
- 卡牌被展示算一次曝光，真正选中才算正样本；跳过奖励时，每张候选牌按半次曝光处理。
- 普通、罕见和稀有分别归一，不会改变三种稀有度本身的抽取比例。
- 会区分牌组里已有 0、1、2 张以上的情况，并从牌组与历史选择中学习卡牌共现关系。
- 使用贝叶斯平滑、低曝光补偿和每局 10% 的历史衰减，避免一次选择把概率永久锁死。

百科大全里可以禁用故障机器人卡牌。禁用后该牌的奖励权重变为 0，但不会消耗 BetterDefect 的改造点数；第一次启动时会迁移 BetterDefect 旧版留下的禁用记录。历史倍率只在百科中打开卡牌详情时显示，不会挤进普通卡面。

## 数据与兼容性

统计和禁用状态保存在游戏用户数据目录的：

```text
DynamicCardOdds/DynamicCardOdds.state.dat
```

替换 DLL 或重新安装不会清空数据；需要重置时再删除这个文件。

当前版本为 [v1.0.2](https://github.com/Yummn/sts2-dynamic-card-odds/releases/tag/v1.0.2)，支持 Android v0.103.2、Android v0.110.1 和 PC v0.107.1。请按压缩包文件名选择对应构建，并把完整的 `DynamicCardOdds` 文件夹放进游戏的 `mods` 目录。

## 从源码构建

准备好对应版本的游戏程序集后，在 `src` 目录运行：

```powershell
dotnet build DynamicCardOdds.csproj -c Release
```

界面和行为检查脚本位于 `tests/`，更详细的版本说明位于 `docs/`。
